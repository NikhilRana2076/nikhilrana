# nikhilrana.com.np

Personal portfolio of **Nikhil Rana** — MSc Artificial Intelligence, University of West London.

Live site: https://nikhilrana.com.np/

## Structure
- `index.html` — the whole site (HTML, CSS and JS in one file, no dependencies)
- `assets/Nikhil_Rana_CV.pdf` — downloadable CV (replace this file to update the CV)
- `CNAME` — custom domain for GitHub Pages

## Adding a headshot
Add `images/headshot.jpg`, then in `index.html` replace `NR` inside `<div class="portrait">` with
`<img src="images/headshot.jpg" alt="Nikhil Rana">`.
